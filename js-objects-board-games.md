# Самостоятельная работа. Прокат настольных игр

В клубе можно взять настольную игру на вечер. Сделайте страницу `index.html` для сотрудника клуба. Он выбирает игру, вводит имя посетителя и нажимает «Выдать». Когда игру приносят обратно, он выбирает её и нажимает «Вернуть».

## Исходные данные

Создайте массив `games` из трёх объектов. Для каждой игры храните название в `title`, число игроков в `players`, а имя человека, который её взял, в `borrower`. Значение `null` означает, что игра свободна.

| `title` | `players` | `borrower` |
| --- | ---: | --- |
| «Каркассон» | 4 | `null` |
| «Доббль» | 6 | `'Аня'` |
| «Шахматы» | 2 | `null` |

## 1. Соберите страницу

Вставьте заготовку в `<body>` и напишите JavaScript в теге `<script>` после неё.

```html
<h1>Прокат настольных игр</h1>
<ul id="gameList"></ul>

<label for="gameSelect">Игра</label>
<select id="gameSelect">
  <option value="0">Каркассон</option>
  <option value="1">Доббль</option>
  <option value="2">Шахматы</option>
</select>

<label for="borrowerName">Имя посетителя</label>
<input id="borrowerName" type="text">
<button id="borrowButton" type="button">Выдать</button>
<button id="returnButton" type="button">Вернуть</button>
<p id="message"></p>
```

В каждом `value` записан индекс игры в массиве. В обработчике кнопки прочитайте `gameSelect.value`, преобразуйте его через `Number()` и получите выбранный объект через `games[index]`.

## 2. Выведите игры из массива

Напишите функцию `renderGames()`. Сначала очистите `<ul>`, затем через `forEach()` создайте по одному `<li>` на игру. Заполните его через `textContent` и добавьте в список через `append()`. Если `borrower` равен `null`, покажите «Свободна», иначе подставьте имя посетителя.

Вызовите `renderGames()` при открытии страницы. Должны появиться три строки:

```text
Каркассон · 4 игрока · Свободна
Доббль · 6 игроков · У Ани
Шахматы · 2 игрока · Свободна
```

Имя можно выводить без склонения, например `Взял(а): Аня`.

## 3. Подключите кнопки

- **«Выдать».** Прочитайте имя из поля. Если оно пустое после `.trim()`, покажите в абзаце «Введите имя». Если игра занята, покажите «Игра уже выдана». Если игра свободна и имя заполнено, запишите имя в `borrower`, покажите «Игра выдана» и обновите список через `renderGames()`.
- **«Вернуть».** Если игра выдана, запишите `null` в `borrower`, покажите «Игра возвращена» и обновите список. Если игра уже свободна, покажите «Игра уже свободна». Для возврата достаточно выбрать игру.

## 4. Проверьте в браузере

1. Выберите «Каркассон» и нажмите «Выдать» с пустым полем. Появится просьба ввести имя, игра останется свободной.
2. Введите «Саша» и выдайте «Каркассон». В строке игры появится имя Саши.
3. Введите «Оля» и снова нажмите «Выдать». Появится сообщение «Игра уже выдана», а в строке останется имя Саши.
4. Нажмите «Вернуть». «Каркассон» снова станет свободен, а «Доббль» по-прежнему будет у Ани.
